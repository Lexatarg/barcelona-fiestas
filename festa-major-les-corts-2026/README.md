# Festa Major de les Corts 2026

An unofficial, hour-by-hour guide to the Festa Major de les Corts in Barcelona,
October 2–12, 2026.
Available in Catalan, Castilian and English.

## About

A single self-contained HTML page. No build step, no dependencies, no tracking.
Each day has a timeline with times, places, directions and calendar links, plus
links to the official sign-up page or website where the program gives one. It
is followed by a list of venues and the practical information from the official
program.

## Source

All information on this page was gathered from the
[official program](https://pro.gestornoticies.dtibcn.cat/gestornoticies-pro/media/Programa.0989ff07.pdf)
of the Festa Major de les Corts 2026, as updated by the City Council, and the
Les Corts district's notices on the guided routes. Please check the program for
the full details and any changes.

This is a personal project, made so that everyone can enjoy the festivities more
easily. It is not an official publication.
