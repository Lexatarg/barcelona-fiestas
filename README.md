# Festes Majors de Barcelona

Guides to Barcelona's festes majors, in Catalan, Castilian and English. This is
a personal project, made so that everyone can enjoy the festivities and have the
best possible experience; it is not an official publication.

Visit the guides at [lexatarg.github.io/festes-majors-barcelona](https://lexatarg.github.io/festes-majors-barcelona/)

## What each guide includes

Each guide is a single page that follows its festival day by day, with the time,
place and a short description of each event from the official program. It
opens with the essentials, five highlights from the program, and ends with the
main places and the practical information the organizers publish, such as safety
advice and where to find support during the festival.

Every event has a Directions link, which opens the maps app of your choice, and
an Add to calendar link, which adds the event to your calendar in the language
you have chosen on the page. You can read every page in Catalan, Castilian or
English, in light or dark mode.

## How the content is made

The sources and information in each guide come only from that festival's
official program or official website, which each guide links in its footer.
The guides are put together with the help of AI tools, which make it easier to
keep up with long festival programs in three languages; nevertheless, every
page is read and checked before it is published.

## Coverage

These guides are a labor of love, made in my free time, so only a limited
number of guides can be maintained at a time, in order to provide the best
possible experience and coverage for every festival that has one.
