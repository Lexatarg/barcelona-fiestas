# La Mercè 2026 — Barcelona

An unofficial, hour-by-hour guide to Barcelona's Festa Major, September 23–27, 2026.
Available in Catalan, Castilian and English.

## About

A single self-contained HTML page. No build step, no dependencies, no tracking.
Chronological timeline for each of the five days, with times, venues, directions
links and practical tips (where to stand, when to arrive, what to wear at the correfoc).

## Source

All information comes from the official programme published by Barcelona City Council.
For the full programme and any last-minute changes, see
[barcelona.cat/lamerce](https://www.barcelona.cat/lamerce/en).

This page was made only to help find and organise that information so more people can
enjoy La Mercè. It is not an official publication.
