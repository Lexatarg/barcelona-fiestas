# Festa Major de l'Esquerra de l'Eixample 2026

An unofficial, hour-by-hour guide to the Festa Major de l'Esquerra de
l'Eixample in Barcelona, October 2–12, 2026.
Available in Catalan, Castilian and English.

## About

A single self-contained HTML page. No build step, no dependencies, no tracking.
Each day has a timeline with times, places, directions and calendar links, plus
links to the festival website where it gives more details. It is followed by a
list of venues and the practical information from the official program.

## Source

All information on this page was gathered from the
[official program](https://pro.gestornoticies.dtibcn.cat/gestornoticies-pro/media/Festa_Major_de_lEsquerra_de_lEixample_-_Programa_2026.1a0d984d.pdf)
published by the Eixample district, the district's notices on the festival,
and the [festival website](https://www.festesesquerraeixample.org/), which
holds the updated schedule. Where the two differ, the guide follows the most
recent information and notes the other version on the event. Please check
the website for the full details and any changes.

This is a personal project, made so that everyone can enjoy the festivities more
easily. It is not an official publication.
